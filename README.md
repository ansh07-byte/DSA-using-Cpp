##  Compilation Setup
The project uses **g++.exe** from MinGW to compile C++ files. The VS Code build task is configured to compile the active C++ file using:

`C:\MinGW\bin\g++.exe`

The compiled `.exe` file is generated in the same directory as the source file.

##  How to Run

1. Clone this repository.
2. Open the folder in Visual Studio Code.
3. Open any `.cpp` file.
4. Press **Ctrl + Shift + B** to build the active file.
5. Run the generated executable.
